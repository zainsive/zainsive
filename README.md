**Google Search Console, GA4 and IndexNow — as an MCP server.**
Ask Claude about your own sites in plain English:

```text
"Which pages lost the most clicks in the last 28 days?"
"Is https://example.com/new-post indexed yet?"
"Which pages rank on page one but get almost no clicks?"
```

Runs on **your own** Google OAuth client — no shared credentials, no third-party data flow.

```bash
uvx seo-analytics-mcp doctor
```
